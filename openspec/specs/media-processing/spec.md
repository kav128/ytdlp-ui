# Получение и подготовка медиа

## Purpose

Определяет поддерживаемые источники и качество медиа, подготовку без перекодирования и передачу результата в хранилище без ограничений размера MVP.

## Requirements

### Requirement: Отдельные публичные ролики

Приложение ДОЛЖНО (SHALL) поддерживать отдельные ролики с публичных источников, поддерживаемых yt-dlp, и отклонять плейлисты и прямые эфиры.

#### Scenario: Поддерживаемый ролик
- **WHEN** URL представляет отдельный публичный ролик поддерживаемого источника
- **THEN** задание может перейти к скачиванию этого ролика

#### Scenario: Плейлист или эфир
- **WHEN** источник представляет плейлист или прямой эфир
- **THEN** обработка отклоняет источник с понятной ошибкой в истории
- **AND** не скачивает плейлист или эфир как обычное задание

### Requirement: Видео с аудио до 1080p

Приложение ДОЛЖНО (SHALL) выбирать видео с аудио с разрешением не выше 1080p и предпочтением MP4. Другой подходящий исходный формат допускается без перекодирования; пользовательский выбор формата в MVP отсутствует.

#### Scenario: Подходящий MP4
- **WHEN** источник предоставляет подходящий MP4 с видео и аудио в пределах 1080p
- **THEN** приложение предпочитает этот вариант

#### Scenario: Другой исходный формат
- **WHEN** подходящий вариант доступен в другом формате
- **THEN** приложение сохраняет его без обязательного преобразования в MP4 и без перекодирования

### Requirement: Отдельная подготовка дорожек

Приложение ДОЛЖНО (SHALL) после скачивания объединять отдельные видео- и аудиодорожки только при необходимости, без перекодирования. Результаты успешного скачивания сохраняются для повтора подготовки.

#### Scenario: Раздельные дорожки
- **WHEN** видео и аудио скачаны отдельно
- **THEN** этап подготовки объединяет их без перекодирования

#### Scenario: Готовый совмещенный файл
- **WHEN** скачанный файл уже содержит нужные видео и аудио
- **THEN** ненужное объединение пропускается

#### Scenario: Ошибка объединения
- **WHEN** объединение завершилось ошибкой, но скачанные дорожки сохранны
- **THEN** ручной повтор использует эти дорожки без нового скачивания

### Requirement: Безопасный запуск медиапроцессов

Приложение ДОЛЖНО (SHALL) передавать пользовательский URL в yt-dlp отдельным аргументом процесса, без конструирования shell-команды из пользовательского ввода.

#### Scenario: Специальные символы URL
- **WHEN** URL содержит символы, имеющие значение для командной оболочки
- **THEN** они остаются частью одного аргумента URL и не исполняются как команды оболочки

### Requirement: Подтвержденная отправка результата

Приложение ДОЛЖНО (SHALL) отправлять подготовленный файл в S3 и подтверждать публикацию перед локальной очисткой. Неопределенный результат отправки требует проверки хранилища перед повторным внешним действием.

#### Scenario: Успешная публикация
- **WHEN** хранилище подтвердило готовый результат
- **THEN** файл доступен в публичной библиотеке, а задание переходит к локальной очистке

#### Scenario: Неизвестный результат отправки
- **WHEN** отправка могла завершиться до потери ответа или сбоя приложения
- **THEN** повтор сначала проверяет результат текущей публикации в S3

### Requirement: Отсутствие ограничений размера и длительности MVP

Приложение ДОЛЖНО (SHALL) обрабатывать поддерживаемые ролики без дополнительных продуктовых ограничений размера файла или длительности. Отправка результата не должна вводить ограничение размера одного запроса S3 как ограничение ролика.

#### Scenario: Крупный или длинный ролик
- **WHEN** поддерживаемый отдельный ролик имеет большой размер или длительность
- **THEN** приложение не отклоняет его из-за собственного лимита размера или длительности MVP
