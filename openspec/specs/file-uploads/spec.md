# Отправка локальных файлов

## Purpose

Позволяет администратору отправлять локальные файлы в публичную библиотеку приложения и получать подтверждение их доступности для скачивания посетителями.

## Requirements

### Requirement: Отправка локального файла администратором

Приложение ДОЛЖНО (SHALL) принимать выбранный локальный файл только от администратора с действующей сессией и публиковать его в настроенном bucket. Для этой операции не требуются URL источника и задание скачивания медиа.

#### Scenario: Отправка администратором

- **WHEN** администратор отправляет один выбранный файл
- **THEN** приложение принимает его для публикации в той же библиотеке
- **AND** не создает задание yt-dlp и не запускает медиапроцессы

#### Scenario: Отправка без прав

- **WHEN** анонимный посетитель или пользователь без административных прав отправляет файл
- **THEN** сервер отклоняет запрос до отправки содержимого в S3

### Requirement: Произвольное содержимое файла

Приложение ДОЛЖНО (SHALL) сохранять байты файла без перекодирования и ограничения перечня расширений или MIME-типов. Новый продуктовый лимит размера в этом изменении не вводится; технические пределы транспорта и хранилища документируются.

#### Scenario: Файл не является медиа

- **WHEN** администратор отправляет документ, архив или другой файл
- **THEN** файл принимается по тем же правилам, что и видео
- **AND** скачанное посетителем содержимое совпадает с отправленным

#### Scenario: Пустой файл

- **WHEN** администратор выбирает файл размером ноль байт
- **THEN** он может быть опубликован и скачан как пустой файл

### Requirement: Подтвержденная публикация в каталоге

Приложение ДОЛЖНО (SHALL) сообщать об успешной отправке только после подтверждения целого объекта в S3. После успеха файл появляется в общем каталоге с названием, размером, датой изменения и публичным действием скачивания.

#### Scenario: Успешная публикация

- **WHEN** хранилище подтвердило полный результат отправки
- **THEN** администратор получает подтверждение и каталог обновляется
- **AND** анонимный посетитель видит файл и скачивает его через бэкенд

#### Scenario: Незавершенная отправка

- **WHEN** отправка еще не завершена или завершилась ошибкой до публикации
- **THEN** приложение не показывает ее как успешную
- **AND** незавершенные части отправки не отображаются как готовый файл

### Requirement: Сохранение имен без перезаписи

Приложение ДОЛЖНО (SHALL) сохранять безопасное отображаемое имя файла и обеспечивать раздельную адресацию файлов с одинаковыми именами. Отправка не должна перезаписывать существующие файлы, в том числе результаты загрузок по URL.

#### Scenario: Совпадающие имена

- **WHEN** администратор отправляет файл с именем уже существующего объекта
- **THEN** оба файла сохраняются как разные объекты и доступны в каталоге
- **AND** содержимое прежнего объекта не изменяется

#### Scenario: Сложное имя

- **WHEN** имя содержит кириллицу, пробелы или специальные символы
- **THEN** безопасное имя корректно показывается и используется при скачивании
- **AND** части имени не интерпретируются как локальный путь или команда

### Requirement: Потоковая отправка и обработка отказов

Приложение ДОЛЖНО (SHALL) передавать содержимое в S3 через бэкенд без загрузки всего файла в память. При ошибке или обрыве соединения незавершенная отправка прекращается, а очистка затрагивает только ее собственные части и ресурсы.

#### Scenario: Большой файл

- **WHEN** размер файла существенно превышает используемый буфер передачи
- **THEN** потребление памяти не растет до размера всего файла
- **AND** учетные данные S3 не передаются браузеру

#### Scenario: Обрыв передачи

- **WHEN** браузер отключился до завершения отправки
- **THEN** сервер прекращает чтение запроса и освобождает ресурсы этой отправки
- **AND** файлы и незавершенные отправки других операций не удаляются

#### Scenario: Неизвестный результат завершения

- **WHEN** хранилище могло завершить публикацию, но ответ был потерян
- **THEN** сервер проверяет собственный уникальный объект перед повтором внешнего действия
- **AND** не удаляет и не перезаписывает чужие объекты
