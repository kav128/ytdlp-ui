# Создание загрузок

## Purpose

Определяет ввод источника, поиск дубликатов и повтор удаленного результата с сохранением идентичности задания и истории попыток.

## Requirements

### Requirement: Создание задания по URL

Приложение ДОЛЖНО (SHALL) принимать от администратора единственный параметр задания — URL источника. Постановка в сохраняемую очередь не должна ожидать завершения скачивания.

#### Scenario: Новый источник
- **WHEN** администратор отправляет допустимый URL, для которого нет задания
- **THEN** создаются логическая загрузка и первая ожидающая попытка
- **AND** HTTP-запрос завершается после постановки задания, пока обработка выполняется в фоне

#### Scenario: Параметры задания
- **WHEN** администратор открывает форму создания
- **THEN** единственный вводимый параметр — URL, без выбора формата, bucket или аргументов yt-dlp

### Requirement: Дубликаты по нормализованному URL

Приложение ДОЛЖНО (SHALL) определять дубликаты по нормализованному URL, сохраняя исходную строку. Удаляются внешние пробелы, нормализуются схема, host и стандартный порт; регистр пути, query-параметры и их порядок сохраняются. Разные ссылки не объединяются по ID ролика.

#### Scenario: Технически эквивалентная ссылка
- **WHEN** URL отличается только внешними пробелами, регистром host или стандартным портом
- **THEN** проверка дубликата находит то же задание

#### Scenario: Разные ссылки на один ролик
- **WHEN** ссылки ведут на один ролик, но имеют разные нормализованные URL
- **THEN** приложение не объединяет их автоматически

#### Scenario: Значимые части URL
- **WHEN** ссылки отличаются регистром пути, query-параметрами или их порядком
- **THEN** эти различия не удаляются при нормализации

### Requirement: Отклонение зарегистрированного URL

Приложение ДОЛЖНО (SHALL) отклонять создание по уже зарегистрированному URL с понятным сообщением, кроме подтвержденного удаления готового результата. Ошибка или отмена прежнего задания допускают явный ручной повтор, а не новую логическую загрузку.

#### Scenario: Действующее или завершенное задание
- **WHEN** URL принадлежит ожидающему, активному, отменяемому заданию или завершенному заданию с доступным файлом
- **THEN** повторное создание отклоняется как дубликат с указанием существующего задания

#### Scenario: Неудачная или отмененная попытка
- **WHEN** URL принадлежит заданию в `Failed` или `Canceled`
- **THEN** создание отклоняется как дубликат
- **AND** администратор может использовать действие повтора существующего задания

### Requirement: Повтор после удаления результата

Приложение ДОЛЖНО (SHALL) при повторной отправке URL удаленного результата создавать новую попытку старого задания со скачивания. Кнопка повтора использует тот же механизм; ID загрузки, URL и прежняя история сохраняются.

#### Scenario: Повторная отправка URL
- **WHEN** администратор отправляет URL задания в `Deleted`
- **THEN** прежнее задание получает новую попытку с начала скачивания
- **AND** новая логическая загрузка не создается

#### Scenario: Готовый результат удален вне приложения
- **WHEN** при административном создании или повторе подтверждено отсутствие прежнего результата в S3
- **THEN** задание фиксирует удаление и допускает новую попытку с прежним ID

#### Scenario: Хранилище не подтвердило отсутствие
- **WHEN** проверка результата завершилась отказом доступа, сетевой ошибкой, timeout или отсутствием bucket
- **THEN** результат не считается удаленным и новое скачивание по этому основанию не запускается

### Requirement: Атомарная постановка попытки

Приложение ДОЛЖНО (SHALL) исключать создание двух логических загрузок по одному нормализованному URL и двух активных попыток одной загрузки при одновременных запросах создания и повтора.

#### Scenario: Одновременное создание
- **WHEN** два запроса одновременно создают задание по одному нормализованному URL
- **THEN** существует только одна логическая загрузка и не более одной активной попытки

#### Scenario: Одновременный повтор удаленного результата
- **WHEN** форма создания и кнопка повтора одновременно обращаются к удаленному заданию
- **THEN** принимается не более одной новой попытки
- **AND** ID задания и история сохраняются
