# Proposal

## Why

Пользователь изменил выбор БД во время реализации MVP: вместо SQLite требуется PostgreSQL. Очередь, история и серверные
сессии должны использовать один актуальный провайдер, а проверки — настоящую целевую СУБД.

## What Changes

- **BREAKING**: EF Core переходит с SQLite на PostgreSQL через Npgsql; меняется строка `ConnectionStrings:AppDatabase`.
- PostgreSQL хранит задания, попытки, этапы, артефакты, публикации и OIDC server tickets. Файлы остаются в S3 и рабочем volume.
- Интеграционные тесты используют изолированный PostgreSQL через Testcontainers, а не SQLite или EF InMemory.
- Обновляются контейнерная конфигурация, локальный Compose, команды и общий технический проект; сервер БД является внешней
  зависимостью приложения. Unit-тесты остаются автономными.
- Сохраняются согласованные HTTP API, OIDC/cookie/CSRF, правила автомата, единственный worker и границы MVP. Переход БД
  включен в текущий этап 4 вместе с сохраняемым API очереди; принятые коммиты этапов 1–3 остаются историей.
- PostgreSQL начинается с чистой БД по выбору пользователя, без импорта заданий, истории и сессий. Существующие
  SQLite-файлы не удаляются и не изменяются переходом; потребуется новый SSO-вход.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `application-build`: целевая PostgreSQL и изолированные интеграционные проверки миграций и ограничений.
- `download-lifecycle`: хранение очереди, этапов и истории в PostgreSQL при прежних правилах переходов.
- `container-delivery`: внешний PostgreSQL и сохраняемые локальные данные приложения вместо SQLite volume.
- `public-library`: ссылки на источник каталога и историю актуализируются для PostgreSQL без изменения S3-контракта.

## Impact

Затронуты CPM/EF provider, DbContext/миграции, ticket store, SQL транзакций и ошибок конкуренции, фабрики и lifecycle
интеграционных тестов, Docker/Compose, readme и OpenSpec. Активный `authentik-sso-and-file-uploads` согласуется с новым
провайдером, сохраняя SSO-контракт. Параллельный change `flibusta-book-downloads` в эту работу не входит.
