# Spec Delta

## MODIFIED Requirements

### Requirement: Последовательная сохраняемая очередь

Приложение ДОЛЖНО (SHALL) хранить очередь в PostgreSQL и выполнять одновременно одно задание; остальные ожидают. Ограничение охватывает скачивание, подготовку, отправку и локальную очистку.

#### Scenario: Несколько заданий

- **WHEN** первое задание выполняется и администратор создает другие
- **THEN** новые задания сохраняются в очереди и не начинают параллельную обработку

#### Scenario: Перезапуск с очередью

- **WHEN** приложение перезапускается с ожидающими заданиями
- **THEN** задания остаются в очереди без повторной отправки URL

### Requirement: История этапов и попыток

Приложение ДОЛЖНО (SHALL) сохранять в PostgreSQL состояния каждого этапа и каждой попытки, ошибку, проваленный этап и точку продолжения. Повтор создает новую попытку той же загрузки с сохранением прежней истории.

#### Scenario: Отказ этапа

- **WHEN** этап завершается ошибкой
- **THEN** задание переходит в `Failed`, сохраняя причину, `FailedState` и `ResumeState`
- **AND** завершенные этапы и их результаты остаются в истории

#### Scenario: Ручной повтор

- **WHEN** администратор повторяет неудачное задание
- **THEN** создается новая попытка с прежним download ID и рассчитанной точкой продолжения
