# Spec Delta

## MODIFIED Requirements

### Requirement: Единая страница библиотеки

Интерфейс ДОЛЖЕН (SHALL) показывать посетителю публичный каталог со скачиванием. После входа администратора та же страница получает управление заданиями, отправку локальных файлов и удаление; отдельная административная страница или вкладка не создается.

#### Scenario: Анонимный просмотр
- **WHEN** посетитель открывает приложение без входа
- **THEN** он видит каталог готовых файлов и действия скачивания

#### Scenario: Вход администратора
- **WHEN** сессия администратора подтверждена
- **THEN** над каталогом появляется блок «Загрузки» с очередью и историей
- **AND** в том же каталоге доступны действия отправки локального файла и удаления

### Requirement: Вход и выход

Интерфейс ДОЛЖЕН (SHALL) предлагать кнопку входа через Authentik в правом верхнем углу и выход после подтвержденного административного входа. Форма локального логина/пароля удаляется. На телефоне вход, выход и все административные действия остаются доступными.

#### Scenario: Открытие формы входа
- **WHEN** посетитель нажимает кнопку входа
- **THEN** браузер начинает OIDC-вход через Authentik с возвратом в библиотеку
- **AND** приложение не открывает собственную форму пароля

#### Scenario: Подтвержденная сессия
- **WHEN** сервер подтвердил вход администратора
- **THEN** доступна кнопка выхода из текущей сессии

#### Scenario: Отказ в административном доступе
- **WHEN** Authentik подтвердил пользователя, но сервер отклонил его административные права
- **THEN** интерфейс показывает локализованный отказ
- **AND** не раскрывает закрытые данные и сохраняет доступ к публичному каталогу

## ADDED Requirements

### Requirement: Форма отправки локального файла

Интерфейс ДОЛЖЕН (SHALL) открывать выбор одного локального файла по административному действию в каталоге. Форма доступна на телефоне и десктопе, показывает имя и состояние отправки, а после успеха обновляет каталог. Пользовательские строки находятся в ресурсах EN/RU.

#### Scenario: Выбор файла
- **WHEN** администратор нажимает «Загрузить файл»
- **THEN** открывается форма выбора файла и отправки
- **AND** URL источника и параметры медиа не запрашиваются

#### Scenario: Успешная отправка
- **WHEN** сервер подтвердил публикацию
- **THEN** UI показывает успех и обновляет каталог с новым файлом

#### Scenario: Ошибка отправки
- **WHEN** запрос не удалось завершить или S3 не подтвердил успех
- **THEN** UI показывает локализованную ошибку без сообщения об успешной публикации
- **AND** администратор может повторно выбрать и отправить файл

#### Scenario: Состояние ожидания
- **WHEN** отправка или подтверждение публикации еще выполняется
- **THEN** UI отображает фактическое состояние ожидания
- **AND** не симулирует процент прогресса и не позволяет повторить ту же отправку двойным нажатием

#### Scenario: Потеря административной сессии
- **WHEN** сессия перестала действовать
- **THEN** клиент скрывает управление отправкой и закрытые данные
- **AND** поздний ответ прежнего запроса не изменяет состояние новой сессии
