## ADDED Requirements

### Requirement: Форма редактирования заголовка файла

Интерфейс ДОЛЖЕН (SHALL) показывать заголовок файла в каталоге при его наличии и исходное имя в остальных случаях. Действие редактирования доступно администратору. Локализованная форма показывает исходное имя и позволяет сохранить или удалить заголовок.

#### Scenario: Администратор меняет заголовок

- **WHEN** администратор сохраняет или удаляет заголовок в форме
- **THEN** каталог обновляется и показывает сохраненный заголовок либо исходное имя после удаления

#### Scenario: Посетитель видит файл с заголовком

- **WHEN** посетитель без административной сессии открывает каталог
- **THEN** для файла с заголовком виден заголовок и доступно скачивание
- **AND** действие редактирования скрыто
