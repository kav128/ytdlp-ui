## Why

Имена файлов из S3 могут быть неудобны для чтения в каталоге. Администратору нужен отдельный заголовок для публикации с сохранением исходного имени при скачивании.

## What Changes

- Администратор может задать, изменить или удалить заголовок любого существующего файла библиотеки.
- Публичный каталог показывает заголовок при его наличии, иначе показывает исходное имя.
- Изменение относится к одному файлу. Массовое редактирование и переименование объектов S3 выходят за его рамки.

### Modified Capabilities
