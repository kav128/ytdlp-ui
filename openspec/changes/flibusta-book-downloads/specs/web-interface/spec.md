# Spec Delta

## MODIFIED Requirements

### Requirement: Форма создания по кнопке

Интерфейс ДОЛЖЕН (SHALL) открывать поле URL и действие отправки по кнопке создания в блоке загрузок. Одна форма принимает ссылки на ролики и карточки Flibusta; источник определяется автоматически. Единственным параметром остается URL. Постоянно открытая форма не требуется.

#### Scenario: Новая загрузка
- **WHEN** администратор нажимает кнопку создания задания
- **THEN** открывается форма с единственным параметром URL и действием отправки

#### Scenario: Карточка книги в общей форме
- **WHEN** администратор вставляет допустимую карточку Flibusta
- **THEN** та же форма создает задание книги
- **AND** выбор источника или формата не требуется

### Requirement: Содержимое карточки задания

Карточка ДОЛЖНА (SHALL) показывать название ролика или книги, текущий этап, прогресс, дату создания, ошибку при наличии и доступные действия. Если title отсутствует, для книги используется известное имя FB2, а до его получения — URL. Для ролика без названия используется URL. Скорость и оставшееся время в MVP не требуются.

#### Scenario: Название еще неизвестно
- **WHEN** у задания еще нет названия и неизвестно имя файла книги
- **THEN** карточка использует URL и показывает текущий этап и дату создания

#### Scenario: Неудачная попытка
- **WHEN** попытка завершилась ошибкой
- **THEN** карточка показывает сведения об ошибке и разрешенные сервером действия

#### Scenario: Название книги
- **WHEN** сервер получил из FB2 title «Автор — Название»
- **THEN** карточка задания отображает этот title

#### Scenario: Книга без названия
- **WHEN** у книги `title=null`, но исходное имя FB2 уже известно
- **THEN** карточка использует имя файла
- **AND** клиент не требует записывать имя файла в title

## ADDED Requirements

### Requirement: Название в публичном каталоге

Интерфейс ДОЛЖЕН (SHALL) отображать название строки библиотеки выражением `title ?? name`. Отсутствующий title не скрывает файл и не препятствует действиям скачивания и административного удаления. Отображаемое название не переименовывает скачиваемый файл.

#### Scenario: Название задано
- **WHEN** у файла есть непустой title и отличающееся исходное имя
- **THEN** публичный каталог показывает title
- **AND** скачивание сохраняет исходное имя файла

#### Scenario: Названия нет
- **WHEN** API вернул `title=null`
- **THEN** каталог показывает name и сохраняет все доступные действия строки
