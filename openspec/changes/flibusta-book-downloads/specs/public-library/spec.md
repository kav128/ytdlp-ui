# Spec Delta

## ADDED Requirements

### Requirement: Необязательное отображаемое название

API библиотеки ДОЛЖЕН (SHALL) возвращать для каждого файла отдельные `name` и nullable `title`. `name` сохраняет имя файла; `title` содержит известное отображаемое название либо `null`. Имя файла не записывается в `title` как запасное значение. Отображение использует `title ?? name`; наличие title не меняет имя скачивания или содержимое файла.

#### Scenario: Файл с названием
- **WHEN** у опубликованного FB2 есть название «Автор — Название», а исходное имя — `original_123.fb2`
- **THEN** API возвращает это название в `title` и `original_123.fb2` в `name`
- **AND** каталог показывает title, а скачивание сохраняет имя `original_123.fb2`

#### Scenario: Файл без названия
- **WHEN** для файла нет известного отображаемого названия
- **THEN** API возвращает `title=null` и исходное `name`
- **AND** каталог отображает `name`

#### Scenario: Внешние и вручную отправленные файлы
- **WHEN** в bucket есть внешний или вручную отправленный файл без title
- **THEN** отсутствие title и связанного задания не исключает файл из полного каталога
- **AND** файл доступен для скачивания под своим именем

### Requirement: Название конкретной публикации

Приложение ДОЛЖНО (SHALL) сохранять известный nullable title вместе с данными конкретной публикации. Перезапуск с сохраненными данными не теряет title. Дополнение названиями не определяет состав каталога: отсутствующий в S3 объект не появляется из-за записи в БД, а объекты без такой записи остаются доступны.

#### Scenario: Название после перезапуска
- **WHEN** приложение перезапущено с прежними данными и опубликованный файл остается в S3
- **THEN** каталог возвращает прежний title и исходное имя файла

#### Scenario: Объект удален извне
- **WHEN** в БД осталось название публикации, но объекта уже нет в S3
- **THEN** название не создает строку каталога для отсутствующего файла

#### Scenario: Новая публикация с совпадающим именем
- **WHEN** новая публикация имеет то же имя файла, что и другая публикация
- **THEN** ее title определяется ее собственными данными
- **AND** title не выбирается только по совпадению имени файла
